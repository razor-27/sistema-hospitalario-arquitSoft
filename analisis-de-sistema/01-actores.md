| **Actor** | **¿Qué necesita realizar?** |
| :--- | :--- |
| **Paciente** | Agendar, consultar, reprogramar y cancelar citas médicas (portal web, app móvil o ventanilla); consultar resultados de laboratorio; recibir recordatorios y notificaciones. |
| **Médico** | Consultar y actualizar la historia clínica electrónica (HCE) del paciente; registrar consultas, diagnósticos y prescripciones; acceder al historial en emergencias. |
| **Enfermería** | Registrar triaje y priorización clínica en Emergencia; consultar la HCE durante los turnos de atención. |
| **Personal de admisión** | Gestionar citas en ventanilla, realizar check-in, admitir y dar de alta a pacientes, y verificar seguro/cobertura. |
| **Técnico (laboratorio, imágenes, farmacia)** | Registrar y publicar resultados de laboratorio e imágenes; integrarse con el sistema mediante eventos. |
| **Administrador del sistema** | Configurar, monitorear y auditar el sistema; gestionar usuarios, roles y reportes de soporte/back-office. |
| **HIS MINSA** | Recibir el reporte de atenciones (Sistema Nacional de Información en Salud). |
| **SUSALUD** | Recibir indicadores y reportes para fiscalización sanitaria. |
| **SIS / Aseguradoras** | Validar la cobertura del paciente. |
| **Laboratorio referencial regional** | Recibir órdenes y enviar resultados de laboratorio. |
| **Plataforma de notificaciones (SMS / correo)** | Enviar recordatorios de cita y alertas a pacientes y personal. |
