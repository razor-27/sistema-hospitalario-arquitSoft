# Sistema de historias clínicas y citas médicas - Hospital de Huamanga

## Nombre

Orlando Paul Nilupu Palomino

## Descripción

Propuesta académica de arquitectura de software para un Sistema Integral de Gestión Hospitalaria (módulos de Citas/Admisión, Historia Clínica Electrónica y Triaje/Emergencia), diseñada a partir de requisitos no funcionales: disponibilidad 99.99%, picos de hasta ~14,000 usuarios concurrentes y recuperación ante desastres.

## Caso de estudio

Hospital de Huamanga (Ayacucho, Perú).

## Curso

Arquitectura de software (IS - 488) - Escuela Profesional de Ingeniería de Sistemas, Universidad Nacional de San Cristóbal de Huamanga.
