| ID | Historia de usuario |
| --- | --- |
| **HU01** | Como paciente, quiero buscar disponibilidad y agendar una cita por especialidad desde el portal o la app móvil, para ser atendido sin acudir a la ventanilla. |
| **HU02** | Como paciente, quiero consultar, reprogramar o cancelar mis citas, para ajustarlas a mi disponibilidad. |
| **HU03** | Como personal de admisión, quiero registrar citas, realizar el check-in y verificar la cobertura del seguro del paciente, para agilizar la atención en ventanilla. |
| **HU04** | Como personal de admisión, quiero admitir y dar de alta a pacientes, para gestionar su ingreso y egreso del hospital. |
| **HU05** | Como médico, quiero consultar y actualizar la historia clínica electrónica de un paciente, para tomar decisiones clínicas con información completa y trazable. |
| **HU06** | Como médico o enfermero de emergencia, quiero registrar el triaje de un paciente y acceder de inmediato a su historial, para priorizar la atención según la gravedad. |
| **HU07** | Como paciente, quiero recibir recordatorios de cita y aviso de resultados disponibles, para no perder mis atenciones y conocer mis resultados. |
| **HU08** | Como administrador del sistema, quiero auditar los accesos a las historias clínicas, para garantizar la privacidad de los datos de salud. |
